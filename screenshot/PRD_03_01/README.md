# PRD_03_01 화면 캡처

`python tests/capture.py screenshot/PRD_03_01`로 만든 것이다.

- OpenRouter가 아니라 **가짜 서버**(`tests/fake_openrouter.py`)에 연결했다. 모델 응답 내용(식재료·레시피 제목)은 가짜 서버가 만든 값이다.
- "냉장고 사진"은 색 막대로 그린 **생성 이미지**이고 실제 사진이 아니다.
- 확인하려는 것은 화면 흐름이다: 가입 → 업로드 → 429 재시도 → 인식 → 레시피 → 저장 → 목록 → 프로필 → 실패 보고 → 삭제 → 로그아웃 → 재로그인 → 인식 실패와 직접 입력.
- 실제 모델 호출 결과는 PC에서 `streamlit run src/app.py`로 확인한다.
